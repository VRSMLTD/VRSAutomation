# Changelog

## 0.7.3

- Fixed the input adapter missing its painted texture (vent grill and patina).
- Build menu icons are now shipped as images instead of being rendered at launch, so they look the same every time.
- Simplified how the mod loads its sound effects.

## 0.7.2

First public release.

- Pipes between chests and machines, drawn with the Link tool, with colors, hop-over crossings and straight-axis snapping.
- Conveyors, splitters and combiners with per-item filters, an on/off switch, a status light and circuit toggling.
- Storage, input and output adapters for chests and machines, with an item screen on storage adapters.
- Machine storage for the furnace, blast furnace, charcoal kiln, eitr refinery, frigid kiln, spinning wheel, windmill, beehive, bird nest and sap extractor, with separate ore and fuel inputs.
- Server-side catch-up: machines keep producing while nobody is nearby.
- Server-synced settings for conveyor speed, costs, pipe length and catch-up.
